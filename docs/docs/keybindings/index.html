Keybindings

The complete built-in keymap. Bindings are grouped by context: the terminal deliberately steals nothing, so every bare key reaches your shell.

Keybindings aren't user-configurable yet — this table is the whole story. If a binding fights something you rely on, that's worth an issue.

How contexts work

Everything terminal-scoped is either modifier-prefixed (cmd-…) or sequence-led (ctrl-w then a key), and bound at the root, so no bare keystroke is taken away from the shell. The file tree, the workspaces panel, and the theme picker are modeless lists with no text input, so bare letters are free there.

Application

cmd-k cmd-ttheme picker
cmd-qquit
cmd-h / alt-cmd-hhide Oxide / hide others

ctrl-cmd-ftoggle full screen

Terminal

cmd-c / cmd-vcopy / paste (bracketed)
cmd-aselect all
cmd-fsearch scrollback — ⏎ older, ⇧⏎ newer, esc closes
cmd-↑ / cmd-↓jump to previous / next prompt
cmd-+ cmd-- cmd-0font size up / down / reset
cmd-clickopen the URL under the pointer
shift + dragselect text even while a program grabs the mouse

Tabs & windows

cmd-tnew tab
cmd-nnew window
cmd-1 … cmd-9select tab 1–9
⌃tab / ⌃⇧tabnext / previous tab
⇧⌘] / ⇧⌘[next / previous tab
cmd-wclose the pane; the window with the last one

Splits & focus

ctrl-w v / cmd-dsplit right
ctrl-w s / cmd-shift-dsplit down
ctrl-w V / ctrl-w Ssplit left / up
ctrl-w h j k lfocus the pane in that direction
cmd-opt-←↓↑→focus the pane in that direction
ctrl-w qclose the focused pane
ctrl-w wtoggle focus: drawer ↔ terminal

The drawer

cmd-bshow / hide the drawer
ctrl-w t / cmd-shift-efocus the file tree
ctrl-w pfocus the workspaces panel
tabswitch between the two panels

In the workspaces panel

In the theme picker

Menu-only commands

These have no default binding:

View → Clear Scrollbackempty the focused pane's history
View → Toggle Status Barshow or hide the bar for this window
File → New Workspacecreate an unnamed workspace
